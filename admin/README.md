# پنل مدیریت فروشگاه

پنل فارسی و RTL مبتنی بر Nuxt 3 و Tailwind است و API را از `NUXT_PUBLIC_API_BASE` دریافت می‌کند.

```bash
copy .env.example .env
npm install
npm run dev
```

برای ورود توسعه از شماره `09120000000` و کد `12345` استفاده کنید. پیش از ورود، backend باید با `php artisan serve` در حال اجرا باشد.

رنگ و تایپوگرافی پایه در `tailwind.config.ts` تعریف شده است؛ برای تغییر هویت فروشگاه، توکن‌های `brand` و تنظیمات سمت backend را عوض کنید.
